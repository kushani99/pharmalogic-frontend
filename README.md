# 🏥 PharmaLogic - Pharmacy Management System

PharmaLogic is a comprehensive **Full-Stack Pharmacy Management System** designed to streamline daily pharmacy operations. It helps manage medicine inventory, track supplier payments, handle customer orders, and manage sales returns efficiently.

## 🚀 Key Features
*   **Real-time Dashboard:** Track today's income, outgoing expenses, and net profit.
*   **Inventory Management:** Add, update, and delete medicine stocks with expiry tracking.
*   **Supplier Management:** Manage supplier profiles and track payment history.
*   **Order System:** Process pharmacy orders and manage delivery/payment status.
*   **Sales Returns:** Handle damaged or returned medicine with automatic stock updates.

## 🛠️ Tech Stack
*   **Frontend:** React.js, Tailwind CSS, Axios
*   **Backend:** Node.js, Express.js
*   **Database:** MySQL
